# -
은행연합회 자동회

선물환 마감 시 은행연합회 프린트를 자동으로 해줍니다

1. 파일을 다운 받고 열어주세요
   py -m pip install playwright openpyxl pywinauto
   py -m playwright install chromium
   py kfb_print_selected-Final


3. 파일을 열먼 CP CODE 바탕으로 원하는 기업을 고를 수 있습니다.
4. 선택 후 로그인 해주세요

5. 팝업에서 로그인 완료를 선택해주세요

6. 파생 상품 조회 화면이 자동으로 열립니다. 
   열리는게 확인 되었다면 '조회 화면 준비 완료'를 클릭해주세요

7. 그 이후부터는 가만히 냅두면 종이가 전체 출력 됩니다
